# Calculadora de Promedio UTM

Aplicación web para calcular el promedio de tres parciales y saber si se aprueba la materia (nota mínima 7).

Proyecto de medio ciclo de Desarrollo Basado en Plataformas, Universidad Técnica de Manabí.

Hecho con HTML, CSS y JavaScript.
